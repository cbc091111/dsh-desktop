# DSH Desktop 🐋

桌面端 **DeepSeek Harness** —— 把官方 DeepSeek Harness 从"网页"变成"装在你电脑上的桌面软件"，再替你包办所有连官方都没做的后勤杂活。

> 大肥鱼理念：壳不重复造轮子，只当官方 DeepSeek Harness 的"监护人"。
> UI 直接内嵌官方 Web（`http://127.0.0.1:3080`），因此 **界面与官方 Web 版 100% 一致**、**兼容全部 DSH 插件**。

> 📄 完整产品简介 & 与官方对比：见 [`docs/INTRO.md`](docs/INTRO.md)

**跟官方比，我们多做了这些：**

| 官方没有的 | 我们的 |
|---|---|
| 一键探测 + 一键部署 | ✅ 双击图标就能用，像装微信一样装 |
| 一键重启 / 强制停止推理 | ✅ 卡了、停不下来，点一下解决（带确认） |
| 启动失败自救 | ✅ 起不来弹窗：强制启动 或 给手把手续 |
| 插件管理 | ✅ 诊断/停用/查看地址简介，自动扫描变动 |
| 自定义主题/壁纸 | ✅ |
| 记忆迁移 | ✅ 从 ChatGPT/Claude/Kimi/豆包 等一键迁入 |
| 自动更新 | ✅ 每天查版本 + 红点提示 + 一键更，可忽略 |
| 使用统计 | ✅ 作者能看到累计/在线 |

## 发布前必改

打开 `src/main/config.js`，把两行占位改成你的 GitHub 信息（或用 `~/.dsh/dsh-desktop/config.json` 覆盖，不改源码）：

```js
owner: 'YOUR_GITHUB_USERNAME',   // ← 你的 GitHub 账号
repo: 'dsh-desktop',
```

生成可人工检查的完整代码报包（放桌面）：

```bash
npm run report
```

## 运行（开发）

要求：Node.js 16+（建议用系统内置安装）

```bash
cd dsh-desktop
npm install          # 首次装依赖（含 Electron）
npm start            # 打开桌面壳
```

## 目录结构

```
src/
  main/      Electron 主进程（探测/部署/拉起/哨兵/主题/记忆）
  preload/   安全桥（contextBridge）
  renderer/  壳 UI（GitHub 开发者式布局）
installers/  一键安装脚本（install.ps1 / install.sh / install.bat）
assets/      图标与壁纸
docs/        架构与发布文档
```
