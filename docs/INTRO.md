# DSH Desktop 🐋 — 产品简介与官方对比

> 一句话：**把 DeepSeek Harness 从"网页"变成"装在你电脑上的桌面软件"，然后替你把连官方都没做好的杂活全包了。**

---

## 一、这是什么

**DSH Desktop** 是一款桌面端 DeepSeek Harness。它不重新做一个 Harness，而是**把官方 DeepSeek Harness 从浏览器网页，变成你双击就能开、开了就能用的桌面程序**，并且在此基础上加了一整套官方没有的"后勤保障"功能。

对你来说的感觉就是：不用再记命令行、不用再开浏览器、不用每次手动折腾了——**像装微信一样装个软件，打开就能用**。

---

## 二、它有哪些优点

| 优点 | 说明 |
|---|---|
| 📦 **一键自动装好** | 首次打开自动检测你有没有装 DeepSeek Harness；没有就问你要不要一键部署，用电脑自带的工具现拉，不用手动敲命令 |
| 🖥 **真正的桌面软件** | 双击图标就开，有独立的桌面窗口、顶栏、侧边栏；不是挤在浏览器标签页里 |
| 🐳 **界面和官方 100% 一样** | 内核就是官方 Web，所以你看到的界面、能用的插件，和官方完全一致，没有任何阉割 |
| 🧯 **一键重启 / 强制停止推理** | 官方卡死、推理停不下来时，点一下就能强制重启或强制停推理（带二次确认，不误伤） |
| 🛟 **起不来也能救** | 官方 Web 没启动成功时，弹窗让你选"强制启动"（丢掉一切阻碍因素硬拽起来），或给出手把手的常见解决办法 |
| 🔌 **插件管家** | 每次打开自动扫描插件变化；点某个插件能看地址/简介，还能一键诊断它运行正不正常、一键停用 |
| 🎨 **自定义主题 & 壁纸** | 换壳颜色、设壁纸背景，让软件用着更顺眼 |
| 🧠 **记忆搬家** | 能把别的 AI 工具（ChatGPT/Claude/Kimi/豆包…）里的重要记忆一键迁移进来，还能自动检查迁得全不全 |
| 🔄 **自动更新** | 我有新版本时自动检测（每天北京时间检查），有更新会在侧边栏亮个小红点，你想更就一键更、想忽略就忽略 |
| 📊 **用的人多了能看见** | 能看到这个软件累计多少人下载、大概多少人用（作者看后台） |

## 三、和官方 DeepSeek Harness 对比

| 对比项 | 官方 DeepSeek Harness（Web） | DSH Desktop（我们的） |
|---|---|---|
| **打开方式** | 要在命令行敲命令启动 `dsh web`，再用浏览器访问 | 双击图标就开，桌面软件窗口 |
| **安装门槛** | 需要装 Node、手动配环境、自己拉包 | 一键探测 + 一键部署，用系统自带工具 |
| **界面一致性** | —（它是原始网页） | 完全一致（内核就是官方 Web） |
| **一键重启** | ❌ 没这个按钮，卡了要自己 kill 进程 | ✅ 点一下重启 |
| **强制停止推理** | ❌ 推理停不下来只能强杀进程（危险） | ✅ 优雅停止，失败才硬停，带确认 |
| **启动失败自救** | ❌ 报错就完，自己搜教程 | ✅ 弹窗问是否强制启动，或给常见解法 |
| **插件管理** | ❌ 只能看列表 | ✅ 诊断/停用/查看地址简介 |
| **自动扫描插件变动** | ❌ | ✅ 每次打开自动比对 |
| **自定义主题壁纸** | ❌ | ✅ 换色/设壁纸 |
| **记忆迁移** | ❌ 不能从别的 AI 工具导记忆 | ✅ 一键迁入 + 完整性自检 |
| **自动更新** | ❌ 版本要靠自己重装 | ✅ 每天查更新 + 红点提示 + 一键更 |
| **使用统计** | ❌ 谁能告诉我多少人用 | ✅ 作者能看到累计/在线 |
| **记忆存储位置** | 固定目录 | ✅ 可指向 K 盘等自定义位置 |

## 四、给不同人的一句话

- **给普通用户**：把 DeepSeek Harness 变成像微信一样好装的桌面软件，还多了好多省心的"后勤功能"。
- **给折腾党**：它不碰你已有的插件和配置，界面插件全兼容官方，只是外面包了一层更好用的壳。
- **给开发者**：配置集中在一个文件，加功能不动结构，随时能 push 更新、发 GitHub。
